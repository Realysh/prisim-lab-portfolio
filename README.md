# prisim_lab | 호텔 리뷰 증강 실험

같은 언어 모델이라도 예시와 호텔 정보를 어떻게 제시하느냐에 따라 결과가 달라질까요? **Llama 3.1 8B**로 생성한 실험용 리뷰를 비교해, 문장 길이·감성 분포·호텔명 노출의 변화를 살폈습니다.

## 실험에서 비교한 것

- **예시 수**: 예시 없는 조건과 몇 개의 예시를 함께 주는 조건을 비교했습니다.
- **호텔 맥락**: 등급·설명·편의시설 중 한 요소씩 빼고 결과를 비교했습니다. 이렇게 한 요소씩 제거해 영향을 보는 방법을 *ablation*이라고 합니다.
- **평가 기준**: 단어 수, VADER 기반 감성 점수, 생성문에 호텔 전체 이름이 나타나는 비율을 봤습니다.

## 기록에서 확인한 점과 한계

편의시설 정보를 뺀 조건에서는 0·1·2개 예시 모두에서 평균 단어 수가 전체 정보를 제공한 조건보다 짧았습니다. 예시를 주지 않았을 때는 평균 327.3단어에서 304.1단어로 줄었습니다. 하지만 **글이 길어졌다는 사실만으로 품질이나 증강 효과가 좋아졌다고 볼 수는 없습니다.** 이 문서는 생성 텍스트의 특성을 다루며, 증강 데이터로 학습한 탐지 모델의 성능 향상을 주장하지 않습니다.

**공개 범위** · 실험 설계와 요약만 제공합니다. 원본·생성 리뷰, 실제 호텔 식별 정보, 실험 코드, 내부 문서와 아카이브는 포함하지 않습니다. 따라서 이 페이지에서 원 실험을 그대로 실행할 수는 없습니다.
